# Alostella

Build a Premium Photography & Film Portfolio Website for ALOSTELLA

1. Project overview

Create a premium, minimalist, visually striking portfolio website for ALOSTELLA, a photography and videography brand based in the UK.

ALOSTELLA captures meaningful moments, events, people, brands and stories through photography and film.

The website should feel like a combination of a high-end editorial magazine, a contemporary creative studio and a cinematic portfolio.

The goal is to attract event organisers, wedding clients, businesses, brands and individuals who need professional photography or video production.

The website must be elegant, easy to navigate, fast, responsive and focused on converting visitors into enquiries.

2. Art direction and visual identity

Use a refined editorial aesthetic with generous whitespace, restrained colours, beautiful typography and large, carefully composed images.

Avoid generic photography website templates, cluttered layouts, excessive animations, gradients, glowing effects, unnecessary cards, bright colours and oversized decorative icons.

Colour palette

Warm ivory: #F5F1E8 — primary background.

Soft charcoal: #20201E — primary text, dark sections and buttons.

Muted champagne: #A58B68 — subtle accents, dividers and small details.

Olive-grey: #77796F — secondary text and understated accents.

Use warm ivory and charcoal for approximately 90% of the interface. Use champagne and olive-grey sparingly.

Create a consistent light theme, with one optional charcoal contact section for visual contrast.

Typography

Logo and brand wordmark: geometric uppercase lettering inspired by Futura, with refined letter spacing.

Large headings: Cormorant Garamond, elegant editorial serif.

Navigation, body text, captions and buttons: DM Sans.

Use Didot only as an optional editorial reference, not as an additional font competing with the main typography.

Use large, expressive headings paired with small, understated labels. Keep body text readable and line lengths comfortable.

Layout principles

Generous whitespace between sections.

Wide margins and a clear grid.

Asymmetric editorial image layouts where appropriate.

Large photographs that dominate the page.

Thin dividers rather than heavy borders.

Minimal rounded corners; avoid making everything look like a card.

Consistent spacing and alignment.

Subtle hover effects and short, smooth transitions.

Respect reduced-motion preferences.

The design should feel intentional, artistic and expensive without being flashy.

3. Website pages and navigation

Create these pages:

Home

Photography

Films

About

Contact

Use a minimal header with the ALOSTELLA wordmark on the left and navigation on the right. Include a discreet but visible “Enquire” link.

On mobile, use a clean, accessible menu with a prominent enquiry link.

Make every navigation item functional and ensure every page has a clear path back to the homepage.

4. Homepage structure

Section A: Hero

Create a spacious, striking hero section.

Display the ALOSTELLA wordmark, followed by this headline:

“Moments, Made Eternal.”

Supporting copy:

“Photography and films for people, places and brands with a story to tell.”

Primary CTA: “Explore the Work”

Secondary CTA: “Start an Enquiry”

Use one large cinematic photograph or a short showreel with a carefully selected poster image. The image should feel emotional, atmospheric and editorial.

Do not use a generic slideshow. Do not autoplay video with sound.

The hero should immediately communicate that ALOSTELLA offers both photography and film.

Section B: Selected Work

Create an editorial portfolio grid with four categories:

Weddings & People

Events

Brands & Campaigns

Films

Use a combination of portrait and landscape images with generous spacing.

Each category should have a subtle title and an understated arrow or hover interaction.

Clicking a category should navigate to its relevant portfolio section or page.

The grid should feel like a curated photography magazine, not a stock gallery.

Section C: Featured Projects

Display three to six featured projects.

Each project should include:

A strong cover photograph or film thumbnail.

Project title.

Project category.

Optional location and year.

A concise project description.

A link to view the complete project.

Create a reusable project-page layout with a large opening image, a short introduction, a carefully sequenced image gallery, embedded film where relevant and a final enquiry CTA.

Use sample project titles only as clearly editable examples. Do not invent real clients, testimonials, awards or commercial experience.

Section D: Photography & Film

Create two spacious editorial sections to explain the two core services.

Photography:
“Still images that preserve the atmosphere, detail and emotion of a moment.”

Film:
“Moving images that bring people, places and stories to life.”

Include a large image or film still for each section, a short description and a link to the relevant portfolio.

Mention weddings, live events, corporate events, commercial photography, brand content and video production as relevant service categories.

Section E: About ALOSTELLA

Use a simple two-column layout with a photograph or behind-the-scenes image on one side and text on the other.

Headline:

“Thoughtful visuals. Stories that stay.”

Explain the approach: understanding the brief, observing meaningful moments, composing carefully and delivering polished visual work.

Keep the copy concise, personal and professional. Do not invent a team, studio location, client history or achievements.

Section F: The Process

Present three simple steps:

01 — Discover
Understand the project, goals, location and creative direction.

02 — Create
Plan and capture the photography or film.

03 — Deliver
Edit and deliver the finished work.

Use typography and whitespace instead of large icons or colourful cards.

Section G: Final enquiry CTA

Create a visually distinctive charcoal section with ivory text.

Headline:

“Let's create something worth remembering.”

Supporting copy:

“Have an event, project or idea in mind? Tell us about it.”

CTA: “Start an Enquiry”

Link directly to the contact page.

Section H: Footer

Include:

ALOSTELLA wordmark.

A short brand description.

Navigation links.

Instagram link placeholder.

Business email placeholder.

UK service area.

Copyright year that updates automatically.

Keep the footer understated and uncluttered.

5. Photography page

Create a dedicated photography portfolio with a minimal introduction and category filters.

Categories:

Weddings

Events

Portraits

Commercial & Brand

Use an editorial grid with varied image proportions and generous spacing.

Filters must work. Each image should open a project page or an accessible lightbox with previous/next controls, close button and keyboard support.

Do not fill the page with too many images. Prioritise curation and image quality.

6. Films page

Create a cinematic film portfolio.

Include:

A featured showreel.

Video project thumbnails.

Project titles and categories.

Short descriptions.

A dedicated project view or modal for each film.

Use click-to-play video with a poster image, accessible controls and no forced audio.

Do not load every full-resolution video on initial page load. Optimise loading and use externally hosted video embeds or an appropriate video hosting service where necessary.

Use clearly marked placeholder media until genuine ALOSTELLA work is added.

7. About page

Create a simple editorial layout with a large image, a concise brand introduction and a clear explanation of the creative approach.

Include photography and film services, the process and a CTA to make an enquiry.

Do not invent personal details, qualifications, client names or experience.

8. Contact page and enquiry form

Create a beautiful, minimal contact page with this headline:

“Tell us what you're planning.”

Include a functional enquiry form with these fields:

Full name — required.

Email address — required.

Service required — Photography, Videography, Both, or Other.

Project type — Wedding, Event, Commercial, Brand Content, Portrait, or Other.

Event or project date — optional.

Location — optional.

Estimated budget — optional.

Project details — required.

Add a submit button labelled “Send Enquiry”.

Validate inputs and display clear success and error messages.

Connect the form to a real submission destination only when configured. If no backend or email integration exists, clearly indicate that setup is required rather than falsely claiming that enquiries have been sent.

Include a clickable email address placeholder and an Instagram link placeholder.

9. Interactions and animations

Use subtle, premium interactions:

Understated image zoom on hover.

Smooth navigation transitions.

Gentle reveal animations that respect reduced-motion settings.

Clear hover and focus states for links and buttons.

Minimal page transitions if they do not affect performance.

Working filters, galleries and enquiry form.

Avoid excessive parallax, animated text on every section, custom cursors, unnecessary loaders and scroll effects that interfere with usability.

All interactions must work on touchscreens as well as desktop.

10. Technical requirements

Build a complete, responsive website using Lovable's supported frontend stack.

Requirements:

Mobile-first responsive design.

Reusable components and consistent design tokens.

Clean, maintainable code.

Semantic HTML and accessible navigation.

Keyboard-accessible controls.

Appropriate colour contrast.

Optimised image sizes and lazy loading.

Fast initial page load.

SEO-friendly page titles, descriptions and headings.

Open Graph metadata for social sharing.

Descriptive image alt text.

Custom favicon using a minimal geometric ALOSTELLA-inspired mark.

Working internal navigation and external links.

Custom 404 page.

No unnecessary user accounts, databases or payment functionality.

Use real, licensed or user-provided images when available. During prototyping, use tasteful temporary photography and make it easy to replace every image. Never present placeholder images as actual client work.

Keep all brand text, portfolio entries, images, service descriptions and social links easy to update.

11. Final quality standard

The finished site should look like a premium independent creative studio, not a generic AI-generated website.

Prioritise:

Strong visual hierarchy.

Beautiful and spacious typography.

Exceptional image presentation.

Clear navigation.

A simple route to enquire.

Excellent mobile experience.

Fast performance.

Before finishing, test all pages, navigation links, gallery interactions, mobile layouts, accessibility basics and form states.

Start by building the homepage and the reusable design system. Keep the design consistent across every page and make the portfolio content easy to replace as ALOSTELLA grows.
